QUICK START IN 3 EASY STEPS (APNE PC PAR CHALANE KA TAREEQA)
--------------------------------------------------------------------------------

1. INSTALL DEPENDENCIES:
   Open your command prompt or PowerShell inside this folder and run:
   > npm install

2. ENVIRONMENT CONFIGURATION:
   The `.env` file is already included in this folder with all required variables.
   - Database: Configured for Supabase REST API & Service Key.
   - Offerwalls: Configured for CPX Research (App ID: 29532).
   - Admin Password: Set in `.env` as `ADMIN_PASSWORD`.

3. START THE APPLICATION:
   Run the development server:
   > npm run dev

   The platform will start at:
   http://localhost:3000

HOW TO IMPORT DATABASE INTO SUPABASE
--------------------------------------------------------------------------------
1. Log into https://supabase.com/dashboard
2. Create or open your project.
3. Click "SQL Editor" on the left menu.
4. Open the file `supabase_schema.sql` included in this folder.
5. Copy all the SQL text, paste it into the Supabase SQL editor, and click "Run".
6. All tables, functions, triggers, and security rules will be created automatically.

--------------------------------------------------------------------------------
HOW TO DEPLOY TO VERCEL (1-CLICK DEPLOYMENT)
--------------------------------------------------------------------------------
1. Go to https://vercel.com and click "Add New..." -> "Project".
2. Import the GitHub repository: https://github.com/paviliong64/Reward-River-v2
3. Settings:
   - Framework Preset: Vite
   - Build Command: npm run build
   - Output Directory: dist
4. Environment Variables:
   Copy all lines from `.env` and paste them into Vercel's Environment Variables.
5. Click "Deploy". Your app will be live on a fast global CDN with custom domain support.
